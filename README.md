# The Problem
Marketers are swimming in data – the results of their fast-moving campaigns. They need an ongoing data analysis at the ready to make campaign adjustments: in messaging, graphics, ad placements and more to tweak the effectiveness and optimize the budget.
The data comes from  multiple sources that change rapidly.  These multiple data sources need to be brought into a single dashboard where the key metrics of all campaigns can be compared side by side to make best strategic adjustments.
Many marketers are still manually gathering the data into a spreadsheet each month, which is incredibly time-consuming and error prone.

# The Goal
There are two goals: One is to have a functioning live dashboard that pulls in all data that marketers can use to optimize campaigns. The second is to have an executive dashboard so that, at a glance, other stakeholders can see the successes attributable to marketing and sales.
Smart Facility Software, a company I have been working with on marketing for a long time, has allowed me to use their marketing and sales data for this project. Smart Facility’s main product is hospital facilities software used in over 600 hospitals in the US.
